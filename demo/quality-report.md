# تقرير جودة الفيديو التجريبي

الحالة: لم يتم تشغيل التصيير في بيئة المستودع بعد. سيُحدّث هذا التقرير تلقائيًا بواسطة scripts/build_demo.py بعد نجاح توليد الصوت والاختبارات وتصدير MP4.

## الأدوات
- Remotion للمشاهد والحركة والنصوص العربية.
- Piper TTS للصوت العربي المحلي.
- Noto Sans Arabic للخط.
- FFmpeg وFFprobe للتصدير والتحقق.

## الملفات المتوقعة
- demo/output/final_9x16.mp4
- demo/output/final_16x9.mp4

## الحالة الحالية
- السيناريو: خمسة مشاهد عربية.
- الصوت: لم يُولّد بعد.
- المزامنة: ستُحسب من مدة ملفات WAV الفعلية.
- RTL: محدد في مكونات العرض، ويتطلب مراجعة بصرية بعد التصيير.
- MP4: ينتظر تشغيل GitHub Actions.

## تشغيل البناء
1. ثبّت piper-tts==1.3.0.
2. شغّل npm install.
3. شغّل python3 scripts/build_demo.py.

ملاحظة: لا يُعد نجاح الفحوص الآلية إثباتًا لجودة النطق؛ يجب الاستماع إلى الناتج قبل النشر.
